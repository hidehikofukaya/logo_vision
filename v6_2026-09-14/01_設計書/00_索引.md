## 決着がついている論点（蒸し返さないこと）

| 論点 | 結論 | 出典 |
|---|---|---|
| 教師データ | **図面 1 枚/品番のみ。**品番ごとの学習は永久に不可 | 要件 |
| 実写データ | **入手不可。**検証は合成のみ | 要件 |
| 撮影側の施策 | **不可。**フラッシュ対・斜光誘導・偏光フィルタとも使えない | 要件 |
| 被覆漏れ 0% | **レンダ上で 0% と読み替える**（承認済み） | 要件 |
| 速度 | **確率マップ 50ms / 最終Bbox 150ms**。100ms 一括から緩和 | 指示 2026-09-13 |
| 表裏の区別 | **不要** | 要件 |
| 追加構造 | 刻印の**外側**のみ。行間を埋めるのは可、干渉は NG | 要件 |
| 画角 | **刻印部の法線**となす角で 45 度まで（板の法線ではない） | 要件 |
| 同軸フラッシュ | 刻印の平坦部は背景と区別できない。**環境光が主信号源** | `04_` |
| 凍結 DINOv2 / ViT | 低テクスチャ・クロスモーダルで崩れる。探索ループに入れない | `06_` §11 |
| 学習済み conv1 の流用 | エッジ密度とほぼ冗長（+1.3pt）。**深い層は逆に悪化** | `06_` §17 |
| 受容野 | **25px 程度が上限。**広げると未知系統への汎化が落ちる | `06_` §19 |
| 学習系の位置づけ | **拒否権を与えない。**採否の最終判定は古典のまま | `06_` §19.6 |
| 評価の軸 | **個別の刻印の認識が主。**最終Bboxは決定論的に出してよい | 指示 2026-09-12 |
| 箱の形 | **方向付き矩形（OBB）。**軸平行は面積を 2.39 倍水増しする | `07_` §10 |
| 画角 | 刻印が画面幅の 20〜70%。**距離でなくレンズで決める** | `05_` §14.1 |

不採用が確定した個別手法の一覧は `CLAUDE.md` の「不採用が確定したもの」を見ること。

## 規約

- 日本語、連番プレフィックス
- 調査で得た数値は**出典 URL を必ず併記**
- 方針を撤回したときは、**撤回した事実と理由を残す**
- 合成データから**検出率や被覆漏れの絶対値は主張しない**。物理の問いと相対比較に限定する
